## How I Approach Engineering

```text
Understand the domain -> define the contract -> enforce the boundary
                      -> test real behavior -> observe and improve
```

My default approach is to make important behavior explicit:

1. **Correctness first** - model invariants and failure cases before optimizing.
2. **Secure boundaries** - authorize every protected action on the server.
3. **Transactional integrity** - keep related state changes atomic and repeatable.
4. **Contract clarity** - keep backend behavior, OpenAPI, and consumers aligned.
5. **Operational readiness** - design for migrations, maintenance, monitoring, and recovery.
6. **Focused delivery** - keep changes scoped, reviewable, tested, and documented.
